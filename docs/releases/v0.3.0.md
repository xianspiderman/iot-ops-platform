# v0.3.0 — Automation and reliability

Released locally on 2026-09-15.

- Added the optional RocketMQ alarm listener and broker-redelivery exception contract.
- Added transactional alarm persistence, business-rule device state update and two-layer `eventId` uniqueness.
- Added business-bad and system-failure records, event lookup, correction confirmation and idempotent replay.
- Added the XXL-JOB timeout handler, indexed candidate query and configurable batch bound.
- Added one-work-order `REQUIRES_NEW` timeout transactions, conditional update, `SYSTEM` track and safe repetition.
- Added execution metrics, isolated failure storage, automatic recovery on rerun and manual compensation.
- Added a reliability management page for alarms, failures, executions and recovery actions.
- Verified 8 unit and 14 MySQL 8.4.11 integration tests plus a Node 24 production build.

Known boundary: the v0.3.0 Compose file still starts only MySQL and Redis. The complete v1.0.0 stack supplies RocketMQ, XXL-JOB admin, backend and frontend services and performs an end-to-end Compose smoke test.
