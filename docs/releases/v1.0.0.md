- 项目、产品、设备、导入、工单、告警和巡检的数据范围检查
- 设备分组与标签的管理端和批量关系维护
- 业务审计日志与管理端查询
- 仪表盘真实汇总、权限感知菜单和可靠性恢复操作

- MySQL、Redis、RocketMQ、XXL-JOB、后端、前端的根目录 Docker Compose

- Java 21、Node 24 与容器构建 GitHub Actions
- 架构、ER 图、流程、演进、ADR、API、测试和启动文档，以及实际项目截图

- 9 个单元测试和 16 个常规 MySQL/Redis 集成测试通过
- TypeScript 检查、Vite 生产构建与 npm 安全审计通过
- 完整 Compose 空库迁移和健康检查通过
- 真实 RocketMQ 首次、重复、业务坏消息、修正重放通过
- 真实 XXL-JOB 注册、周期触发和执行回调通过

- 1,000 行导入查询阶段可选基准通过；结果与边界见 `docs/testing.md`

## 升级提示

从 v0.3.0 启动时，Flyway 自动执行 V4。已有 `admin` 用户会被关联到管理员角色；新增 `operator` 演示用户通过启动初始化器写入 BCrypt 密码。公开部署必须替换 Compose 演示口令并收紧基础组件端口。

## 已知边界

- 同步导入最多 10,000 行；尚未实现异步队列或暂存表。
- 巡检每次最多 100 个候选；尚未分片。
- 权限失效面向当前模块化单体实例；多实例缓存广播尚未引入。
- 前端全量 Element Plus 入口包存在体积提示，但不影响构建和演示；需要真实首屏数据后再按收益拆分。
